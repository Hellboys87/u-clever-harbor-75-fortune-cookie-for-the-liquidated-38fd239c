A Node program that writes one original fortune cookie line — 18 words, 101 characters — for a crypto trader who has just been liquidated to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The fortune keeps the cookie voice and the loss in it: the market took the trader's margin, not their mojo, and patience will pay them back.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
